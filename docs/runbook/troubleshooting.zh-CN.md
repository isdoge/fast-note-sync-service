# 排错与常见问题

先保留服务端日志、客户端错误码和发生时间。临时把 `log.level` 调成 `info` 或 `debug` 可获得更多上下文；不要在公开问题中粘贴完整令牌或配置密钥。

## 常见现象

### 同步一直不动

- **原因**：上游存在 Protobuf 协商后首条消息丢失、分页确认先于分页队列登记到达两类竞态，均会卡住当前连接；3.7.0 已修复。插件主动断线时，本轮状态也可能未重置。
- **处理**：服务端升级到 3.7.0，插件升级到 2.5.0，然后完全重连或重启插件并手动同步。主动断线遗留的一轮可能等到插件 5 分钟停滞检测后重启；旧版没有该检测时会一直卡住。若仍卡住，记录最后一个 Action、错误码和服务端对应 Trace ID。
- **不要假定重试必然成功**：持续下载失败的文件会让该类型下一轮从上次成功基线重新拉取，这是避免漏同步的现有行为。

### 设备频繁掉线重连

- **原因**：Cloudflare Tunnel 等链路可能丢 pong；`trusted-proxies` 错误还会让绑定 IP 的 WebGUI 令牌看到变化的客户端地址。完全没有响应的连接默认约 100 秒被关闭。
- **处理**：核对代理 Upgrade 头与 `trusted-proxies`；Tunnel 可试 `app.ws-ping-wait: 180`，必要时调大 `ws-ping-interval`。WebGUI 因 IP 变化掉线时可关闭 `security.webgui-login-token-bind-ip`。
- **限制**：持续丢 pong 时调大超时只会延后重连；当前插件没有空闲应用层心跳。正常上传数据帧也会刷新存活时间，不应把慢上行直接当作死连接。

### 文件时间显示为 1970 年

- **原因**：部分客户端把秒级 ctime/mtime 当毫秒上报。
- **处理**：升级到服务端 3.7.0、插件 2.5.0。服务端写入入口归一化秒值，首次启动迁移 `note/file/folder` 存量数据。
- **限制**：插件本地已落盘的 1970 年显示不会自动更正，下次修改文件后恢复；不要删除本地文件再拉取，因为删除会同步。归一化把 `0 < v < 1e11` 当秒，因此 1970–1973 年真实毫秒值也会被误乘 1000。

### 换机器、重建容器或迁移后令牌全部失效

- **原因**：用户 JWT 的 HMAC 密钥是 `security.auth-token-key + "_" + 机器标识`，分享令牌也包含机器标识。机器标识优先取系统 machine ID，其次主板序列号，最后才使用 `config/.server_uuid`；仅保留该 UUID 文件不能覆盖前两种来源发生变化的情况。
- **当前规避办法**：保留原机器标识来源和原密钥。无法保留时，在 WebGUI 重新登录，并为插件/API 重新签发、配置令牌；分享链接失效后重新创建。当前版本没有独立的静态签名密钥配置，不能把 `.server_uuid` 当成通用迁移方案。此问题计划后续修复，3.7.0 尚未修复。

### Protobuf decode failed / 解码失败后一直不能同步

- **原因**：客户端与服务端帧格式或协商状态不一致；上游还存在已协商 Protobuf 后把 JSON 降级帧强按 Protobuf 解码的问题。
- **处理**：两端升级到插件 2.5.0 / 服务端 3.7.0。服务端会识别 `Action|{...}` JSON 文本帧，即使连接已协商 Protobuf；插件解码失败会在本次连接退回 JSON。之后重连。自研客户端需检查 `pv`、`pb`、`protocol=protobuf` 和 `ClientInfo.protobuf` 是否一致，详见 `docs/ws_api.md`。

### 升级后受限令牌调用被拒（库管理、清空回收站、递归删目录、MCP）

- **原因**：本版把库级破坏操作从笔记/附件写权限中拆出为独立功能点。`vault_w`（新建/改名/删除库）、`note_purge` / `file_purge`（清空整个回收站）、递归删目录需同时具备笔记与附件写权限；MCP 工具要求令牌显式包含 `mcp` 协议，新签发令牌不再自动附带。REST 分享接口要求笔记读/写权限。`f:*`（不限功能）令牌不受影响。
- **处理**：错误码 315 的 details 会指明缺少的功能点（如 `vault_w`、`note_purge`）或库。手动令牌在 WebGUI 令牌管理里补勾对应能力或改用 `*`；MCP 令牌的协议维度显式加 `mcp`；OAuth 连接器申请对应 scope（`vaults:write`、`notes:purge`、`files:purge`）。受限令牌报“缺少 vault”属 WebSocket 消息缺库字段，补上即可。
- **不要放开限制迁就旧令牌**：这些拒绝正是修复的越权面；需要旧粒度权限时重新签发令牌。

### 附件下载或 WebGUI 请求报 313

- **原因**：WebGUI 登录令牌绑定了签发时的 User-Agent，浏览器 UA 或代理改写后的 UA 与记录不一致。
- **处理**：先确认代理不无故改写 UA。确实需要改写时设置 `security.webgui-login-token-bind-ua: false`，再重新登录。关闭后不再校验 UA；312 则对应 IP 不匹配，不能用 UA 开关解决。

### Git 同步提示 unsupported git protocol / only http and https

- **原因**：仓库只接受 HTTP(S)，`ssh://`、`git://`、`user@host:path`、服务器本地路径均被拒绝。
- **处理**：改成仓库的 `http://` 或 `https://` 地址，并填写对应 HTTP 凭据。验证操作有 20 秒超时。

### Git 同步提示 private network access not allowed

- **原因**：目标或 DNS 解析结果属于被拦截的内网地址；`100.64.0.0/10` 包含 Tailscale 地址。
- **处理**：在 `git.allowed-private-hosts` 配置最小必要范围。主机名条目还需 IP/CIDR 覆盖每个私网解析结果；实际连接地址也会校验。详见反向代理与内网访问文档。

### MySQL / MariaDB 建表或运行异常

- **原因**：3.7.0 虽修复了 path 索引和零日期问题，仍有分享表、Git 同步表、同步日志表相关未解决错误。
- **处理**：本版不要使用 MySQL/MariaDB；使用 SQLite 或 PostgreSQL。不同数据库之间的数据迁移步骤未在仓库中提供，不要只改 `database.type` 就假定数据会迁移。

### 32 位 ARM 没有全文搜索

- **原因**：`GOARCH=arm` 时 Bleve 会自动关闭，避免 zapx 未对齐的 64 位原子操作崩溃。
- **处理**：这是当前保护行为，启动日志会记录警告；配置 `fts-bleve-enabled: true` 不能覆盖。其他同步功能继续运行。使用非 32 位 ARM 构建可按配置启用全文搜索。

## 错误码速查

业务码通常在 HTTP 200 的响应体中返回，不等于 HTTP 状态码。下表列出用户操作可能直接看到的码；`details` 会提供更具体原因。

| 码 | 含义 | 常见触发与处理 |
| --- | --- | --- |
| 0 | 失败 | 未细分失败，结合 details 与日志。 |
| 1 / 2 / 3 / 4 / 5 / 6 | 成功 / 创建 / 更新 / 删除 / 密码修改 / 无更新 | 成功码，不按故障处理。 |
| 300 | 服务器内部错误 | 未分类内部错误，查同时段日志。 |
| 301 | 数据库查询失败 | 数据库连接、权限、SQL 或结构问题。 |
| 302 | 服务器繁忙 | Worker Pool 满或关闭；稍后重试并检查负载。 |
| 303 | 请求过多 | 登录/请求限流，降低重试频率。 |
| 304 | API 不存在 | 路径、版本或代理转发不匹配。 |
| 305 | 参数验证失败 | 请求字段、路径、vault 或格式不合法，查看 details。 |
| 306 | 访问令牌校验失败 | 签名、令牌状态、类型或绑定信息无效。 |
| 307 | 尚未登录 | 缺少有效登录状态，重新认证。 |
| 308 | 登录状态失效 | 重新登录。 |
| 309 | 缺少用户令牌 | 请求未带用户 Token。 |
| 310 | 令牌过期 | 重新登录或签发令牌。 |
| 311 | 令牌生成失败 | 查签发日志与有效期配置。 |
| 312 | 令牌 IP 受限 | 客户端 IP 改变或 trusted-proxies 错误。 |
| 313 | 令牌 UA 受限 | UA 改变或被代理改写。 |
| 314 | 令牌客户端类型受限 | Token 的 ClientType 与请求客户端不符。 |
| 315 | 令牌 Scope 受限 | Token 缺少当前协议/客户端/函数权限，或库受限。 |
| 400 | 用户注册失败 | 查看 details；注册关闭时有专用 410。 |

| 408 | 当前密码验证错误 | 核对旧密码。 |
| 409 | 两次密码不一致 | 重新输入。 |
| 410 | 注册关闭 | 管理员开启 `user.register-is-enable`，或创建账号。 |
| 411 | 需要管理员权限 | 使用 `user.admin-uid` 对应账号。 |
| 412 | 本地文件系统禁用 | 启用 `storage.local-fs.is-enable`。 |
| 413 | 用户更新失败 | 查字段和数据库日志。 |
| 414 | 无法拉黑管理员 | 换非管理员目标。 |
| 420 / 421 | 库不存在 / 已存在 | 核对库名与创建状态。 |
| 422 / 423 | 存储类型无效 / 云存储类型无效 | 改用服务端支持的类型。 |
| 430 / 431 | 笔记不存在 / 已存在 | 刷新状态后重试。 |
| 432 | 获取笔记失败 | 查正文文件与数据库日志。 |

| 435 | 笔记删除失败 | 查 details；刷新后确认是否已删除。 |
| 436 | 笔记列表失败 | 查数据库或索引日志。 |
