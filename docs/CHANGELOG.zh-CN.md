## v3.8.0
> *2026/11/19*

条目末尾括号内为上游 issue / PR 编号：不带前缀的属于 `haierkeys/fast-note-sync-service`，`插件#` 属于 `haierkeys/obsidian-fast-note-sync`。

### ✨ 新增

- **WebGUI**: 新增实时更新：其它设备或客户端新增、修改、删除、改名笔记与附件，修改配置，或分享状态变化时，打开着的页面会自动刷新对应的列表、目录树、附件预览和正在查看的笔记，不必手动刷新。正在编辑且有未保存修改时不会被远端内容覆盖，而是提示冲突并暂停自动保存，由你选择“重新加载”或“保留当前”；笔记被远端删除时停止保存并给出提示。服务端通过 `GET /api/webgui/events`（SSE）推送，只包含元数据（不含笔记正文、附件与配置内容），按用户与笔记库隔离；经反向代理访问时需为该路径关闭响应缓冲，见 `docs/runbook/reverse-proxy.zh-CN.md`。远端改名后页面与自动保存跟随新路径；恢复历史版本后编辑器自动刷新；远端更新附件后重新打开预览不再命中旧缓存，切换笔记库时关闭上一个库的预览；远端删除或改名目录时，正在编辑的笔记、画布与附件预览随之处理。
- **WebGUI**: 附件新增文本与代码文件的只读预览（超出大小上限或判定为二进制的文件不预览）；搜索时可同时检索附件（#357）。预览把服务端错误响应当成文件内容、笔记列表与搜索结果里点 `.canvas` 被当作文本打开的问题也已修正。
- **令牌**: 新增 `security.token-signing-key` 配置。启用稳定签名密钥之后新签发的令牌不再依赖机器标识，重建容器、重装系统或迁移机器后仍然有效；留空时首次启动会在 storage 目录生成并持久化随机密钥文件（`token-signing.key`，权限 600）。未配置固定密钥前按机器标识签发的旧令牌在换机器后仍会失效，同机原地升级不受影响（#439）。
- **令牌**: 新增功能点 `vault_r`（库信息读取）、`vault_w`（库新建、改名、删除）、`note_purge` 与 `file_purge`（清空整个笔记 / 附件回收站），可在 WebGUI 令牌表单中勾选；切换笔记库只读 / 管理权限时自动取消互斥的另一项。OAuth scope 相应新增 `vaults:write`、`notes:purge`、`files:purge`。
- **配置**: 新增 `oauth.vaults`，可为 OAuth 鉴权的 MCP 连接器限定可访问的笔记库（默认不限制）。
- **配置**: 新增 `security.strict-empty-protocol`（默认关闭），开启后协议维度为空的存量令牌一律拒绝。
- **部署**: 新增远程部署脚本 `scripts/remote_deploy.sh`，只需服务器地址与 SSH 账号即可从本地一键部署到远端 Linux 服务器，支持“二进制 + systemd”与 Docker Compose 两种方式，部署后自动做健康检查并给出安全配置提示。脚本同时处理特殊安装包文件名、校验端口参数、核对指定的二进制版本、兼容 sudo 用户部署，清理临时文件不影响同机其它部署；在“二进制 ↔ Docker”之间切换时先停掉旧实例并确认停止，停不掉就中止。
- **部署**: 安装脚本 `scripts/quest_install.sh` 支持非交互执行，新增 `--yes` 与 `--tarball` 参数（对应环境变量 `FNS_ASSUME_YES`、`FNS_INSTALL_TARBALL`），可离线安装本地安装包。
- **文档**: 新增运维手册 `docs/runbook/`（中、英文）：配置项参考、反向代理与内网访问、升级指南、排错与错误码、远程部署。

- **同步**: 修复大库同步时一次上报大量删除可能被服务端静默丢弃、已删笔记重新出现的问题。
- **同步**: 修复刚连接、尚未完成首次同步的客户端可能把其它笔记库的实时变更写入本地的问题。
- **附件**: 修复上传会话复用后完成确认可能被客户端丢弃、导致上传名额被占住并卡住同步的问题。
- **附件**: 修复附件上传最后一片落库失败时会话残留、客户端重试永久卡住的问题。
- **附件**: 修复并发上传同一附件时可能出现状态错乱的问题。
- **同步**: 修复补推单条资源遇到数据库瞬时错误时可能误让客户端删除本地文件的问题。
- **目录**: 修复目录同步删除检查在哈希碰撞或查询出错时可能误广播删除的问题；只读令牌不再广播目录删除。
- **配置同步**: 修复配置内容未变但未带修改时间时仍会被改写时间戳并广播的问题。
- **历史**: 修复路径哈希碰撞时笔记历史版本列表报错的问题。
- **OAuth**: 修复库白名单中库名包含逗号时被误拆、可能额外授权其它笔记库的问题。
- **令牌**: 修复令牌被吊销后已建立的实时事件流仍可能短暂收到通知的问题。

- **同步**: 修复增量同步时，本地与服务端内容、修改时间都一致的笔记、附件和配置仍被要求重新上传的问题（每次重连都上报全部本地文件的第三方客户端尤其明显）；没有写入权限的设备上报时也不再逐条刷“上传被拒绝”的警告日志。
- **配置同步**: 修复客户端上传配置未带修改时间时服务端把修改时间存成 0，导致之后服务端上更新的配置无法下发给这些客户端的问题。
- **附件**: 修复附件重复上传被判定为无需更新（或只需更新修改时间）后，分片上传的临时文件残留在服务器临时目录的问题。

- **附件**: 修复文件监听触发的上传检查与一轮同步交错时，上传完成的确认没有带上本轮同步的标识、客户端不把它计入同步进度，偶发“附件都传完了但整轮同步不结束”的问题（2.5.0 及更早的插件搭配新服务端同样受益）。
- **同步**: 修复服务端处理笔记、附件、配置的修改、删除、改名与附件检查出错（权限不足、目标已存在、数据库错误等）时，出错回应里不带对应文件路径的问题：插件发请求前占用的并发名额无法归还，累积后整轮同步不结束，停滞检测也不触发。现在出错回应带上路径；权限或库访问被拒绝、服务繁忙时同样处理。
- **日志**: 修复退出 Obsidian 或关闭浏览器页签时，正常断开的连接被记成错误日志的问题。
- **部署**: 修复安装脚本在无 TTY 环境下因 `tput` 报错的问题。
- **部署**: 修复安装脚本后台启动的服务进程继承 SSH 会话通道、导致远程安装时 SSH 连接挂起的问题。
- **数据库**: 修复 MySQL / MariaDB 后端的多处建表与数据正确性问题：TEXT 列带默认值、全文索引表的保留字列名未加引号、索引长度超限导致建表失败；首次并发访问时重复建表报错；路径不区分大小写导致 `Note.md` 与 `note.md` 互相覆盖（路径、路径哈希与库名列在 MySQL / MariaDB 上改为二进制类型）；带反斜杠的历史路径迁移在这两种数据库上找不到表。已在 MySQL 8.4 与 MariaDB 11.4 上通过全流程实测，使用前请先阅读配置说明里 `user-database` 的部分。

- **数据库**: 从 3.7.0 及更早版本升级时，新增 MySQL / MariaDB 升级前预检：若存量路径超过 1024 字节或笔记库名超过 255 字节，启动会在执行任何表结构变更（`ALTER TABLE`）之前报出超长表列、行数与样本 id，避免升级中途因数据截断失败；缩短或删除这些记录后重新启动即可继续升级。已升级完成的实例只在启动时读取元数据，不扫描业务表。

- **WebGUI**: 修复提示框关闭时的竞态、键盘操作穿透到下层界面，以及信息框点击遮罩无法关闭的问题。

### 🔒 安全

- **管理员**: `user.admin-uid` 未配置（为 `0`）时不再把所有登录用户都当作管理员，改为现存用户中 UID 最小者为管理员，启动日志提示显式配置。
- **管理接口**: 在线客户端列表与踢出接口只允许管理员从 WebGUI 调用；服务端升级接口要求“管理员 + `config_w` 功能点”，只有笔记或附件权限的受限令牌不能再触发升级。
- **管理接口**: 管理配置（含签名密钥）只对管理员返回，非管理员登录用户不能读取或改写。
- **令牌**: 签发令牌时不再自动追加 MCP 协议；省略协议维度的新令牌只有 REST 权限，已签发的令牌不受影响。
- **令牌**: 登录令牌不能通过更新接口改写权限范围；更新令牌时省略库限制字段不再把原有的库白名单清空。
- **MCP**: 库的新建、改名、删除要求 `vault_w`，清空整个回收站要求 `note_purge` / `file_purge`，递归删除目录要求同时具备笔记与附件写权限；功能维为通配的令牌不受影响。
- **MCP**: 工具在缺失认证上下文时不再回退到首个用户执行，改为拒绝。
- **OAuth**: `vaults:read` 不再附带笔记读权限。
- **REST / WebSocket**: 分享接口要求笔记读 / 写权限；普通鉴权组里未归类的接口一律拒绝；限定了笔记库的令牌发来不带库字段的 WebSocket 消息改为拒绝。
- **WebSocket**: 实时广播改为按笔记库投递：限定了笔记库的令牌不再收到同账号其它库的广播（含笔记正文）；每条连接只收到自己同步过的库的广播，不校验库名的第三方客户端不会再把其它库的内容写进本地。
- **WebGUI**: `run-mode: debug` 不再跳过 WebGUI 客户端校验。
- **启动**: OAuth 启用且允许静态令牌直连、或默认 scope 含通配时，启动日志给出安全提醒。

### 🔄 变更

- **管理员**: 多用户且未配置 `user.admin-uid` 的实例，升级后只有最早注册的用户是管理员；要指定其他人请显式配置 `user.admin-uid`。
- **令牌**: 用旧接口或脚本以 `rest,ws` 之类的旧式范围新建令牌后再调用 MCP 会被拒绝，新建时需显式带上 `mcp` 或 `*`。
- **令牌**: 清空整个笔记 / 附件回收站现在需要单独的 `note_purge` / `file_purge` 权限（单条清理不变）；旧的手工令牌如需清空回收站，请在令牌管理中补勾对应权限。登录签发的令牌不受影响。
- **令牌**: 在管理界面修改令牌的库范围或权限后，已在线的同步连接与实时事件流会立即断开并按新范围重新鉴权（只改有效期等不会断）。
- **MCP / OAuth**: 受限令牌与默认 scope 的 OAuth 连接器不能再改名、删除笔记库或清空整个回收站；需要时在令牌功能维勾选对应功能点，或在 OAuth 侧申请 `vaults:write`、`notes:purge`、`files:purge`。只申请了 `vaults:read` 的连接器需加申请 `notes:read` 才能读笔记。
- **调试**: 本地用无头工具或 Swagger 调 WebGUI 接口时需显式带 `x-client: webgui` 请求头。
- **WebSocket**: 一条连接只接收自己发过请求的那些笔记库的实时广播；连接在第一次带库名请求之前不再接收带库名的广播（不带库名的用户级通知照常）。官方插件本来就会丢弃库名不符的广播，不受影响。
- **远程部署**: 远程部署脚本在“二进制 ↔ Docker”之间切换部署形态时会先停掉旧实例并确认停止，停不掉就中止。
- **数据库**: 主库使用 PostgreSQL / MySQL 且 `user-database.type` 留空的部署，用户数据实际仍存放在 SQLite 文件里，与主库类型无关；要存进主库需显式设置 `user-database.type` 与连接参数。配置文件注释已按实际行为更正。
- **WebGUI**: 管理界面里的仓库、更新与问题反馈链接改为指向本仓库（isdoge），并移除 cnb 镜像源。
- **数据库**: 已在使用 MySQL / MariaDB 的实例，升级后首次启动会把路径、路径哈希与库名列改为二进制类型并重建相关索引，数据量大时这一步会锁表一段时间；建议升级前备份。
- **升级**: 首次启动会执行一次存量数据迁移，把带反斜杠的历史路径改成正斜杠，并同步更新历史、链接与全文索引；目标路径被存活记录占用时，带反斜杠的那一条改名为 `*.conflict.<时间戳>.*` 保留，不覆盖、不合并、不删除任何数据；目标上只有已删除记录时直接迁移。迁移结果写入启动日志，失败的条目下次启动自动重试；建议升级前备份数据目录（#451）。

## v3.7.0
> *2026/11/18*

本版本起为 isdoge 独立维护的修复版，从上游 3.6.1 分出，不跟随上游版本。更新检查与下载改为 isdoge GitHub，镜像改为 `ghcr.io/isdoge/fast-note-sync-service`，移除 cnb 发布与下载源。

条目末尾括号内为上游 issue / PR 编号：不带前缀的属于 `haierkeys/fast-note-sync-service`，`插件#` 属于 `haierkeys/obsidian-fast-note-sync`。

### ✨ 新增

- **MCP**: 新增 7 个知识查询工具：`note_search`、`note_list_broken_links`、`note_list_orphans`、`note_list_tags`、`note_list_recent`、`note_list_by_prefix`、`vault_stats`（#509）。
- **MCP**: 支持通过 OpenAI Secure MCP Tunnel 接入 ChatGPT 连接器（#469）。
- **MCP**: `note_list`、`file_list` 支持分页并返回总数（#510）。
- **配置**: 新增 `app.ws-ping-interval`（默认 `25` 秒）与 `app.ws-ping-wait`（默认 `60` 秒），WebSocket 心跳间隔与存活超时可调（#503）。
- **配置**: 新增 `security.webgui-login-token-bind-ua`（默认 `true`），反向代理或远程访问网关改写 User-Agent 导致附件下载报 313 时可关闭（#336）。
- **Git 同步**: 新增 `git.allowed-private-hosts` 私网仓库白名单（默认空，保持全部拦截），支持主机名、IP 与 CIDR，并校验实际连接地址（#410）。
- **令牌**: 启动时及此后每天自动清理已过期的登录令牌，范围与手动“清理过期令牌”一致（#337 #426）。

### 🚀 优化

- **WebSocket**: 收到任意上行数据帧都刷新连接存活时间，慢速上行的客户端不再被误判超时断开（#484）。
- **WebSocket**: 存活超时后先补发一次 ping 并宽限一个心跳周期，仍无响应才断开；经 Cloudflare Tunnel 等会吞掉 pong 的链路可调大 `app.ws-ping-wait`（#503）。
- **同步**: 分页下发缓存在所属连接存活期间保留，长时间同步不再因缓存过期中断（#490）。
- **同步**: 同一连接发起新一轮同步时清理上一轮残留的分页缓存。
- **数据库**: PostgreSQL / MySQL 下同一用户的各张表共用一个连接池，连接数不再随表数量成倍增长；连接池创建移出全局锁，不再阻塞其它用户的请求（#231）。
- **历史**: 大笔记生成历史补丁改为流式写出，降低内存峰值；空笔记不再在每次启动时被重新调度（#499）。

## v3.6.0
> *2026/07/09*

### ✨ 新增

- **同步**: 新增同步协议滑动窗口流水线机制。上行清单分批与下行分页由原来的逐批/逐页等待确认（stop-and-wait）升级为多批/多页并发在途，大幅缩短大笔记库全量同步耗时（实测上行提速 6.64 倍、下行提速 3.19 倍）。协议全程能力协商、双向向后兼容：新旧客户端与新旧服务端任意搭配均自动退回原有逐批/逐页模式，无需强制升级。
- **配置**: 新增 `pipeline-window-up`（默认 `8`）与 `pipeline-window-down`（默认 `4`）两项配置，分别控制上/下行流水线的在途批次/页数；显式设为 `0` 即可实时回滚到 stop-and-wait 逐批/逐页模式，作为流水线功能的运行时安全阀（管理后台同步支持读写这两项配置）。

### 🚀 优化

- **同步**: 下行同步分块大小 `sync-down-chunk-num` 默认值由 `50` 提升到 `200`，减少 stop-and-wait 场景下的分页往返次数。
- **同步**: 全量/增量同步下发改为按需读取笔记正文、仅在实际分页下发时才回填内容，避免大笔记库同步时的整表串行盲读与全量内容物化进内存。
- **数据库**: `note` 表补充 `(vault_id, path_hash)` 复合索引，消除全量上传场景下点查退化为全表扫描的问题。
- **数据库**: 消除全文索引写入、修改校验、批量删除等链路中的多处冗余重复查询（`upsertFTS` 复用调用方刚写入的记录、`NoteModify` 合并重复查询、批量删除笔记去除逐条存在性检查）。
- **同步**: 写队列 worker 改为非阻塞批量取出已排队操作，减少逐条操作反复进入调度队列的开销。
- **同步**: `sync_log` 写入由逐条裸 goroutine 改为有界 channel + 单 worker 批量写入，避免大批量上传瞬间产生海量并发写入。
- **同步**: 广播消息改为锁外并发发送，避免慢设备拖慢同一用户其他在线设备的消息接收。
- **性能**: 笔记 diff 按基准文本长度动态启用行级预处理，加速大笔记合并。
- **性能**: 文件夹计数改为一次 `GROUP BY` 聚合查询，消除逐文件夹 2 次 `COUNT` 的 N+1 查询；文件路径迁移检查、`git-sync` 启用状态判断等高频路径加入进程内缓存，减少重复 IO 与查库。

### 🛠️ 修复

- **同步**: 修复并发写入同一笔记/文件时误用 `singleflight` 导致后到写入静默丢失、却仍收到成功确认的问题（数据丢失级）。
- **同步**: 修复笔记/附件重命名时 `os.Rename` 落盘失败被静默吞掉、导致数据库与磁盘状态不一致的问题。
- **稳定性**: 为备份、Git 同步等后台裸 goroutine 补充 panic recover，避免单个任务异常导致整个服务进程崩溃。
- **同步**: 上传分批协议按批次序号去重，避免客户端重传导致服务端重复写入与计数错误。
- **同步**: 下行分页 `PageAck` 与预期不符时服务端兜底重发当前页，避免客户端卡死等待至 10 分钟会话超时。
- **并发**: 修复 WebSocket 客户端信息字段无锁读写，在并行处理开启时可能产生的数据竞态。
- **稳定性**: 数据库连接池 LRU 淘汰增加最短空闲保护，避免误关仍在使用中的连接。
- **配置**: 修复运行时回滚安全阀半失效问题——`pipeline-window-up`/`pipeline-window-down` 显式设为 `0` 时，原先会被配置二次加载逻辑静默覆盖回默认值，现已正确识别并保留显式 `0`。
- **同步**: 修复分页信封 `pageIndex` 第 0 页与非分页广播消息在 Protobuf 模式下的零值歧义。

## v3.0.0
> *2026/05/14*

> [!WARNING]
> **注意事项**：本次更新引入了全新的令牌架构，会导致旧版所有授权失效。升级后您需要对所有客户端设备进行重新授权。

### 🔐 核心更新：全新有状态令牌权限系统

本项目重构了底层的安全架构，从单一无状态令牌升级为 **有状态多维度（协议、客户端、功能）** 校验令牌：
- **多维度校验**：
  - **协议控制**：支持对 `REST API`、`WebSocket`、`MCP` 等不同访问协议及场景进行独立授权与限制。
  - **客户端限制**：支持通过通配符绑定特定设备（如 `obsidian*`），实现“一机一令”。
  - **内容控制**：细化至笔记读写 (`note_r/w`)、附件管理 (`file_r/w`)、系统配置 (`config_r/w`) 等原子级权限。
- **世代校验与令牌轮转 (Rotation)**：
  - 引入 `Nonce` 世代机制。令牌在存在泄露风险时可进行轮转操作，旧世代令牌将立即失效，有效防范令牌被盗用的风险。
- **动态环境绑定**：
  - 支持对令牌进行 **IP 地址** 和 **User-Agent** 的静态或通配符绑定，用于在非安全环境下限制令牌使用行为。
- **令牌访问统计**：
  - 服务端将会记录所有令牌的访问行为，支持实时监控各令牌的调用协议、来源 IP 及客户端版本。

### ✨ 新增

- **备份**: 新增备份任务密码加密设置。全量与增量备份任务新增灵活的备份包加密策略，支持“不设密码、手动固定密码、系统随机密码”三种配置模式，显著提升备份数据的存储安全性。

### 🛠️ 修复

- **云存储**: 升级阿里云 OSS v2 SDK 驱动，修复存储配置连接测试失败及区域识别问题。

### 🚀 优化

- **性能**: 优化文件处理性能。调整哈希计算阈值为 10MB，通过延迟创建物理目录大幅减少文件系统 I/O 开销。
- **协议**: 优化协议标准化。所有 WebSocket 返回消息强制包含 `vault` 字段，确保多库同步状态的一致性。
- **安全**: 安全加固。备份历史记录中的敏感密码字段默认开启掩码处理，支持手动解密查看。
